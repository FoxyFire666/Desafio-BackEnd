Desafio BackEnd - Códigos de teste
==============================================================================================================================================================================
1- Iniciar a API (na primeira janela do PowerShell):
cd "C:\Users\Pichau\Documents\Desafio Backend"
go run ./cmd/server
==============================================================================================================================================================================
2- Abrir o endereço local e conferir se a API está ativa (na segunda janela do PowerShell):
Pelo navegador:
Start-Process http://localhost:8080/health/live
Pelo PowerShell:
Invoke-RestMethod http://localhost:8080/health/live
==============================================================================================================================================================================
3- Criar uma carteira:
$wallet1 = Invoke-RestMethod -Method Post `
  -Uri http://localhost:8080/wallets `
  -ContentType "application/json" `
  -Body '{"playerId":"jogador-teste-01","initialBalance":{"amount":"100.00","currency":"BRL"}}'
$wallet1
==============================================================================================================================================================================
4- Fazer uma aposta:
$betBody = @{
  providerId = "provider-a"
  externalTransactionId = "transacao-aposta-01"
  playerId = "jogador-teste-01"
  walletId = $wallet1.id
  roundId = "rodada-01"
  gameId = "jogo-teste"
  kind = "BET"
  money = @{ amount = "20.00"; currency = "BRL" }
} | ConvertTo-Json -Depth 3

Invoke-RestMethod -Method Post `
  -Uri http://localhost:8080/wagering/transactions `
  -ContentType "application/json" `
  -Headers @{"Idempotency-Key"="chave-aposta-01"} `
  -Body $betBody
==============================================================================================================================================================================
5- Simular uma vitória:
$winBody = @{
  providerId = "provider-a"
  externalTransactionId = "transacao-vitoria-01"
  playerId = "jogador-teste-01"
  walletId = $wallet1.id

  gameId = "jogo-teste"
  kind = "WIN"
  money = @{ amount = "100.00"; currency = "BRL" }

Invoke-RestMethod -Method Post `

  -Body $winBody
==============================================================================================================================================================================
6- Simular uma perda:
$lossBody = @{
  providerId = "provider-a"
  externalTransactionId = "transacao-derrota-01"
